# OrganiRack+ Mobile

Professional inventory management and order picking system for Android and iOS devices.

> **Documentation in English?** See [INDEX.md](INDEX.md) for complete navigation in both languages.

---

## Descripción General

OrganiRack+ Mobile es una aplicación React Native de nivel producción que permite al personal del almacén gestionar eficientemente operaciones de picking de inventario mediante sincronización en tiempo real con un backend Laravel.

## Development Scripts

```bash
npm start       # Start development server
npm run android # Android emulator
npm run ios     # iOS simulator
npm run web     # Web browser
npm run lint    # Run ESLint
```
