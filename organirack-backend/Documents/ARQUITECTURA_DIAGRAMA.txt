                           📊 FLUJO DE UN REQUEST

Paso 1: Usuario entra a /dashboard (o dashboard-test.html)
        ↓
Paso 2: JavaScript detecta necesidad de datos
        ↓
Paso 3: fetch() → GET /api/dashboard/metrics + Token
        ↓
Paso 4: Laravel route → DashboardController::metrics()
        ↓
Paso 5: Controller llama → DashboardService::getDashboardMetrics()
        ↓
Paso 6: Service ejecuta 5 métodos en paralelo:
        ├─ getOrdersByState()
        ├─ getOrdersByPriority()
        ├─ getInventoryByCategory()
        ├─ getWarehouseOccupancy()
        └─ getCriticalStockProducts()
        ↓
Paso 7: Cada método → Queries SQL optimizadas a BD
        ↓
Paso 8: Resultados agregados → Array JSON
        ↓
Paso 9: response()->json($consolidatedData) → HTTP 200
        ↓
Paso 10: JavaScript recibe JSON
        ↓
Paso 11: Chart.js renderiza gráficas
        ↓
Paso 12: Usuario ve 📊 Gráficas en pantalla ✅

                        ✨ CASOS DE USO POR GRÁFICA

  1️⃣  ESTADO DE ÓRDENES (Dona)
      → Gerente ve en un vistazo cuántas órdenes están en qué estado
      → Tomar decisiones rápidas sobre prioridades

  2️⃣  ÓRDENES POR PRIORIDAD (Barras)
      → Identificar si hay muchas órdenes urgentes
      → Planificar recursos del almacén

  3️⃣  INVENTARIO POR CATEGORÍA (Barras Horizontal)
      → Ver qué categorías tienen más/"menos stock
      → Optimizar espacio del almacén

  4️⃣  OCUPACIÓN DE ALMACENES (Progreso)
      → Identificar almacenes llenos/vacíos
      → Redistributir inventario si es necesario

  5️⃣  STOCK CRÍTICO (Tabla)
      → Alertas de productos a punto de agotarse
      → Iniciar proceso de reorden automáticamente
